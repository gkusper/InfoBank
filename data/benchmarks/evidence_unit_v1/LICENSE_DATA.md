# Data License

The MailEx project README observed during preparation states that the dataset is
distributed under the Creative Commons Attribution-ShareAlike 4.0 International
license (CC BY-SA 4.0):

https://creativecommons.org/licenses/by-sa/4.0/legalcode

No separate LICENSE, COPYING, or dataset-internal license file was found in the
downloaded archive. The redistribution decision for this benchmark is therefore
based on the MailEx README license statement and should be reviewed again before
publication.

MailEx is derived from real Enron e-mail. This benchmark redistributes only a
small experiment-specific derived subset, not the raw MailEx corpus. E-mail
addresses, phone-like strings, participant fields, and selected person-name
tokens are pseudonymized, and only action-related excerpts are included.

MailEx-derived benchmark material in this directory should be treated as
modified material under CC BY-SA 4.0 unless later source-license review requires
a different handling. InfoBank-authored scripts, schemas, and documentation are
part of the InfoBank project and are not MailEx source code.
