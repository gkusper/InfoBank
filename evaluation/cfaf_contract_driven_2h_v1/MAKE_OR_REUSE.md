## Availability, licensing and absent modules

Exact probes, versions, metadata licences, hashes and AST function inventory are in component_inventory.json. The active study venv has pyarrow26.0.0 (Apache2), datasets5.1.0 (Apache2), numpy2.5.4 (metadata lists BSD/MIT/etc.) and pytest9.2.0 (MIT). Python stdlib and SQLite FTS5 work. ChromaDB, PyMuPDF, Pydantic, SQLAlchemy, spaCy, NetworkX, Sentence Transformers, Casbin, DuckDB and Haystack are not installed in this venv; no stack was installed or recommended as a measured replacement. Requirements declarations are not proof of runtime availability or verified third-party licences.

The measured branch does not contain document_processing.py, routing.py, aggregate_executor.py or citation_service.py. Actual existing policy_engine/evidence_service/controlled_failure/ai_service modules were inspected. A previously cached main source at8079f29 contains aggregate_executor.py and citation_service.py; both were inspected by source/hash only. That partial cached main has no local LICENSE, so its licence was not independently verified and neither is newly adopted. The existing tested evaluation aggregate adapter already remains in historical code. No absent module or licence is invented.

SQLite FTS5 is available but not used as a replacement retriever. No local NLI model/checkpoint is established, and no spaCy/NetworkX/Casbin/Haystack migration is proposed merely because these libraries exist. Keep production ingestion/database services in their normal environment; retain supplied evidence for this fair study.

## Future one-call ablation — design only

A future named configuration could ask one Structured Outputs call for evidence properties plus candidate answer, then retain deterministic authorization/sufficiency checks and deterministic contract rendering. This may remove a realization call, but is not executed/validated here. It cannot be presented as measured architecture, token savings or semantic accuracy improvement.
