# QASPER test gold mapping: fixed before test download/eligibility inspection

Version: qasper-test-text-eligibility-1. Original QASPER 0.3 annotations remain unchanged and scorer-only. This is a conservative text-representable subset, not the entire QASPER benchmark.

Source integrity requires the complete serialized reference-paper record as distributed: nonempty original paper ID/title/abstract, full_text a list of objects with string section_name and list-of-string paragraphs, at least one nonempty paragraph, figures_and_tables a list of objects with string caption/file fields. Every original section and caption is available to the adapter before any context truncation. This verifies the distributed record, not recovery of PDF image contents or guaranteed completeness of the source extraction.

Each original answer wrapper must contain a dict answer with exactly the original unanswerable, extractive_spans, yes_no, free_form_answer, evidence and highlighted_evidence fields. unanswerable must be Boolean; spans/evidence/highlights are lists of strings, extractive spans nonempty if present; free-form is a string; yes_no is Boolean or null. Answerable annotations must select exactly one nonempty representation: extractive spans, nonempty free-form, or Boolean yes/no. Boolean false is a usable No, not missing. Unanswerable annotations must have none of those substantive representations. A malformed or missing annotation makes the question UNKNOWN rather than being silently dropped.

FULL requires every annotation valid and unanswerable=false, no true/false disagreement among explicit Boolean answers, and text-representable original evidence for EVERY annotation. Each annotation must have at least one nonempty original evidence item, and every item must match an original full-text paragraph or abstract after whitespace normalization. Any FLOAT SELECTED table/figure evidence makes this strict primary question UNKNOWN, even if its caption or another text passage might suffice; captions alone do not establish image/table body contents. Unmatched text evidence and empty evidence also yield UNKNOWN. This intentionally conservative rule may exclude text-answerable questions; it is fixed before inspection, never adapted to particular cases. Exact matching here establishes source representability, not semantic answer correctness.

CFAF requires every original annotation valid and unanswerable=true, no substantive representation, and the same source-integrity checks. It does not require an evidence annotation for an absent answer. UNKNOWN includes mixed answerability, malformed/missing answer structures, explicit contradictory Boolean answers, incomplete source records, unsupported nontextual evidence, empty answerable evidence, unmatched original textual evidence or other mechanically indeterminate structures. Reasons may overlap and their counts are reported as such; modes form a disjoint partition. No model output or qualitative judgment changes eligibility/gold.

Tier M: at least two original annotations unanimously supporting the mechanically derived mode. Tier S: one valid original annotation. These tiers describe original answerability consensus, not guaranteed factual correctness; free-form/extractive content disagreement is not resolved by a second model. UNKNOWN receives no derived binary mode/tier. All original annotations and derived outcomes are separate files.

Original source/title/abstract/full_text/captions are model-available subject to the common pilot retrieval budget; original evidence/answers/worker or annotation IDs/expected modes remain scorer-only. Eligibility evidence matching cannot select runtime paragraphs. A later retrieval omission is a pipeline limitation: never change FULL to CFAF after retrieval or outputs.
