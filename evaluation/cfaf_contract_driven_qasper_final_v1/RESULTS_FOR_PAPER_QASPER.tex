\subsection{Dataset Registry, Provenance, and Scope}

This revised comparative presentation retains the previous Dataset1 and Dataset2 observations without rerunning them and replaces only Dataset3 with a new QASPER test evaluation. The earlier 160-case GaRAGe report remains unchanged as \emph{Archived Dataset3-v1 -- GaRAGe Grounding Study}. The cohorts are not pooled into one accuracy estimate.

\begin{itemize}

    \item \textbf{Dataset1 (InfoBank):} the 40 previously exposed, authors' synthetic P1--P5 cases forming 20 matched pairs. The 40 new independently authored InfoBank holdout cases contemplated for future work were neither available nor accessed in this study.

    \item \textbf{Dataset2 (RefusalBench-NQ):} 40 previously exposed eligible cases sampled with seed 20261029. The established exclusion of contradiction-related cases was retained, and original \texttt{ANSWER\_CORRECTLY} and eligible \texttt{REFUSE\_*} labels were mapped deterministically to \textsc{full} and CFAF, respectively. A prior content-protection rule prohibited opening 30 reserved source groups; these, together with 18 additional untouched groups, were preserved. The 40 evaluated cases therefore form a \emph{development fallback}, not an independent final test. The benchmark source is \url{https://huggingface.co/datasets/aashiqmuhamed/RefusalBench-NQ}.

\item \textbf{Dataset3 (QASPER):} 80 questions from the original version~0.3 test split, 40 mapped \textsc{full} and 40 CFAF cases, selected with seed 20261029 from distinct papers after excluding all papers exposed in both earlier validation pilots. The primary pool is Tier M. Source: \url{https://huggingface.co/datasets/allenai/qasper}.

\end{itemize}

\subsection{QASPER Mapping, Eligibility, and Frozen Protocol}

The original test archive was pinned by SHA-256 \texttt{72a52a41193e2838\allowbreak b8074f80ac074b94\allowbreak f956b84886c36a61\allowbreak c58a7df4171bdd72}. It contains 1451 questions in 416 papers. Mapping and eligibility rules were registered before test-label inspection; selection, source/runtime hashes, scoring, prompts and model settings were frozen before API execution.

\textsc{full} requires unanimously answerable, structurally valid annotations with usable extractive, free-form or Boolean answers, no explicit contradictory yes/no answers, and representable original textual evidence for every annotation. Boolean No is a usable answer. CFAF requires unanimously unanswerable valid annotations without a simultaneous substantive answer and a complete distributed reference-paper record. Mixed/missing/malformed answers, contradictory Boolean annotations and unsupported source representations are UNKNOWN. The conservative text-only eligibility rule excludes any answerable annotation selecting FLOAT SELECTED figure/table evidence, empty original evidence or text not found in the source. Caption availability is not treated as access to image/table contents.

This yields 854 eligible \textsc{full}, 79 CFAF and 518 UNKNOWN questions. Tier~M has at least two agreeing annotations (834 \textsc{full}, 76 CFAF); Tier~S has one (20 and 3). Both M classes support forty distinct papers, so all 80 selected questions are Tier~M. Tier~S has no measured performance estimate. Human consensus does not guarantee factual correctness or complete agreement on answer content.

The preregistered paper-first random allocation preserves distinct papers while reserving enough papers for both classes, then draws one eligible question within each selected paper. This is not uniform sampling over all questions. No sample was replaced after outputs. The balanced, text-representable, higher-consensus subset is not representative of the full test distribution.

The same original title, abstract, paragraphs and textual captions are supplied to A/B/C. The unchanged pilot adapter uses a whole paper when its analysis envelope fits 110000 serialized ASCII bytes, otherwise deterministic SQLite FTS5/BM25 whole-paragraph selection in original order. The actual API envelope is bounded by 120000. Human evidence never selects runtime context. 76 cases use the full distributed text and 4 use a retrieved subset. 1 gold-\textsc{full} cases lose at least one annotated evidence item; 0 retain no complete annotated evidence set. These are retrieval diagnostics, not grounds to relabel gold.

The original A/B/C implementation is preserved from \texttt{experiment/cfaf-contract-driven-v1}: A is ordinary selective RAG, B deterministically guards the exact A generation with zero extra calls, and C uses frozen sparse-source analysis, the original mode selector and LLM response realization. The separately developing one-call/component implementation is not used. All systems use \texttt{gpt-4o-mini}, temperature~0, one repetition; analysis/generation ceilings remain 1500/512 tokens, with an optional 500-token query-only profile. No embedding, external judge or second verifier is used. Model-observed deployment(s): \texttt{gpt-4o-mini-2024-07-18}.

Prompts, schemas, semantic rules, thresholds and output budgets are identical to the historical comparison. Benchmark source granularity and the pilot context allowance differ from historical GaRAGe inputs. Therefore this is a revised presentation of preserved development results and a new test cohort, not a perfectly input-controlled or wholly newly independent experiment.

Primary accuracy credits only policy-valid, non-operational mode agreement over all planned cases. Safe technical fallbacks do not count as correct CFAF. Precision conditions on valid non-operational predictions; recall includes failures. Joint paper-cluster bootstrap intervals use 2000 replicates and seed 20261029 for QASPER; historical InfoBank pair and RefusalBench source-group intervals are retained. All gold, reference answers and human evidence remain scorer-only.

On Dataset2, C correctly classified 29/40 cases, compared with 30/40 for A/B. C alone corrected two cases and B alone corrected three, producing a net difference of $-2.5$ percentage points (95\% source-group bootstrap interval: $-13.2$ to $7.9$ points). C reduced erroneous \textsc{full} decisions on gold-CFAF cases from seven to five, but increased unnecessary restrictions on gold-\textsc{full} cases from three to six. Its higher CFAF recall (80.8\% vs.~73.1\%) was accompanied by lower \textsc{full} recall (57.1\% vs.~78.6\%). There is therefore \emph{no consistent mode-classification advantage} across these two exposed development cohorts. No statistical-significance claim is made.

The difference between selected mode and completed answer is material. On Dataset1, exact original reason-class agreement was 72.5\% for C versus 60.0\% for A/B; fulfilment-status agreement was 80.0\% versus 60.0\%. A coarse original-gold marker-presence diagnostic on gold-\textsc{full} cases was only 31.2\% for C versus 50.0\% for A/B. These are mechanical annotation-linked diagnostics, not independent factual-answer or explanation-quality judgements. Accordingly, C's 100\% Dataset1 mode score must \emph{not} be described as 100\% correct generated answers. The P5 no-view rule and its zero-call behavior were shared with all three systems, and no policy violation was observed in the bounded study; this does not independently stress-test arbitrary private-source leakage.

\subsection{Dataset3 Evidence, Answer Quality, and Operational Limits}

Original human answers and evidence support additional diagnostics, not a second independent ground truth for generated claims. Reference-valid internal windows are not public citations or entailment proofs. A/B do not expose passage selection in the shared six-field schema; their selection precision is uninstrumented rather than assigned zero. C has 8 operational failures. Its validated paragraph-selection macro precision/recall/F1 on gold-FULL cases is 45.3\%/52.2\%/41.2\%. These overlap metrics are not factually complete-answer accuracy. No verified public citation renderer was added.

Agent-produced review is explicitly non-independent and unblinded. Apparent annotation/document discrepancies remain flagged without changing gold, removing cases or adjusting the headline metric. A FULL mode does not prove that the answer covers all requested relations, conditions and precision. A single original human judgment would not by itself establish that a disagreeing generated answer is hallucinated; this primary cohort instead uses multiple-annotation consensus, which can also be mistaken.

\subsection{Interpretation and Threats to Validity}

Replacing GaRAGe with QASPER strengthens the reproducibility of a binary answerability comparison because labels are derived explicitly from original annotations. It does not make the labels infallible, convert exposed Dataset1/2 development results into independent tests, or establish a general factual-answer advantage. The QASPER cohort is balanced, paper-diverse, text-representable and higher-consensus by design; it excludes 518 UNKNOWN questions and does not estimate natural test prevalence. Source extraction may omit nontextual information; retrieval loss remains a pipeline limitation. Test questions are locally unexposed but public-benchmark familiarity of the pretrained model cannot be excluded or quantified here.

Original free-form/extractive answers can disagree semantically despite mode consensus. Independent claim-support, answer-completeness and annotation adjudication remain absent; the agent review is diagnostic only. C differs from B in extra analysis, prompts and fulfilment logic, so comparison does not isolate the selector. The original boundary scaffolding is not a completed library-substitution or one-call architecture, and neither that implementation nor a second semantic verifier is evaluated. The historical GaRAGe grounding findings remain archived and are not pooled with QASPER binary metrics.
