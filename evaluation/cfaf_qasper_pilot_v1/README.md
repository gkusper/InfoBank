# QASPER pilot protocol and reproduction

This is the provisionally registered `Dataset3-QASPER-v2-candidate`, an exploratory balanced development experiment. Dataset1 remains InfoBank; Dataset2 remains RefusalBench-NQ. Original GaRAGe experiments retain their Dataset3-v1 identity and are unchanged.

Start: 2026-10-29 10:37:00 UTC, conservatively rounded down from initial inspection. Hard stop: 11:37:00 UTC. Stop initiating model calls at 11:27:00 UTC. Only gpt-4o-mini, temperature 0, one repetition, maximum 50 attempts including failures; no retries, embeddings, judge, independent verification service, or larger dataset run. The local branch starts at bfd80bbfe2ccbb251da46bdc22b791dad5b9341f.

The analysis limit remains 1500 tokens; Standard/CFAF generation remains 512; optional query-only profile fallback remains 500. The previous conservative 60000 serialized-byte input bound is raised before any model call for scientific papers. The paper-selection envelope targets 110000 ASCII-serialized bytes. Each actual complete API request is bounded by 120000 bytes, with space for profile overhead; this is a conservative token upper bound, below the model's existing 128000-token context even with the 1500-token output allowance. Exact runtime cap and hashes are frozen in EXPERIMENT_MANIFEST.json. This changes context allowance only, not semantic rules.

The runtime whitelist contains only question, title, abstract, full-text sections/paragraphs and textual figure/table captions. Title and abstract are always present. The complete paper is used if it fits the target envelope. Otherwise an in-memory SQLite FTS5 index ranks original paragraphs and captions using BM25 over OR-connected Unicode question terms (length at least two); ties use original paragraph order. Whole paragraphs are admitted while the bound permits and restored to original order. No gold evidence, annotations, worker IDs or labels participate. The same projected evidence and ordering is supplied to A/B/C. Gold FULL labels remain FULL when retrieval omits evidence. Captions do not supply figure/table image contents.

A reuses the existing ordinary selective-RAG prompt and common six-field schema. B validates the same exact A output; it makes zero additional calls and has no CFAF sufficiency gate. C is a byte-identical copy of the current measured sparse-source CFAF pipeline: eight stages, existing query profiling/RDA, source inventory, sparse assessment, RECV/sufficiency, original selector, realization and output validation. Its optional profile fallback is query-only. No source restrictions are invented: every supplied public paragraph has FULL access. No experimental R1 span alias ablation or public citation renderer is added.

Implementation is frozen after tests and before model execution. Every original tracked working file is protected by SHA-256. All completed cases are saved immediately, no resampling/reruns. Failed or unexecuted cases stay in the ten-case denominator. Operational fallbacks never count as correct evidential refusals. Human evidence and reference answers are joined only by the scorer. Qualitative reviews are explicitly Codex-produced and non-independent; evidence overlap is not entailment or complete correctness.

Reproduction order in a new isolated checkout: download the pinned original archive and dev member; `python -m evaluation.cfaf_qasper_pilot_v1.selection`; `python -m evaluation.cfaf_qasper_pilot_v1.adapter`; run synthetic and isolated regression tests; `python -m evaluation.cfaf_qasper_pilot_v1.runner freeze`; `python -m evaluation.cfaf_qasper_pilot_v1.runner run`; run scorer, audits and reporting. One-shot assertions prevent overwriting selections or results. An explicit new authorized clock state is needed; never alter this experiment's expired state to rerun it.

Private artifacts are under ignored `datasets/` and `local/`: original archive/dev JSON, original annotations, full runtime inputs, API payloads, raw generations, and detailed case review. Required public RUNTIME_INPUTS.jsonl records context hashes, inclusion counts and retrieval decisions, allowing integrity checks without publishing original papers. RESULTS.jsonl records derived predictions/statuses; local/CASE_REPORT.md supplies the complete requested qualitative detail.

No merge or push is performed. User publishes manually after review.
